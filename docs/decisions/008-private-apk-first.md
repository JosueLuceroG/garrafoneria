# ADR-008: APK privada antes de Play Store

**Status:** Accepted

## Context

El MVP se distribuirá inicialmente a un grupo controlado de repartidores y no requiere publicación pública.

## Decision

La app Android se prepara como APK privada/development build. La publicación en Play Store no forma parte del MVP.

## Alternatives considered

No hay alternativas registradas.

## Consequences

- Se necesita activación y revocación de dispositivos antes de una operación real.
- No se deben embebir credenciales administrativas.
- La distribución pública y su pipeline quedan para una fase posterior.
